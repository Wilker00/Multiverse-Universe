# Brand Voice and Product Language — Multiverse

Multiverse sounds calm, exact, and evidence-led. It explains what happened, what is known, and what needs verification without pretending the system is more capable than it is.

## Voice Rules

| Use | Avoid |
| --- | --- |
| “Run the checks” | “Unlock autonomous intelligence” |
| “This memory helped on 3 related tasks” | “The agent has learned permanently” |
| “Needs review” | “Probably correct” |
| “No relevant verified memory found” | “The knowledge base is thinking” |
| “Compare approaches” | “Agents debate to find the truth” |

- Prefer common words and short sentences.
- Introduce one technical term at a time and define it where it first appears.
- State whether information is observed, inferred, proposed, or verified.
- Name the action and its consequence on buttons.
- Never use emoji, decorative AI language, invented certainty, or unexplained benchmark claims.

## Product Terms

- **Run**: One attempt to complete a task.
- **Trace**: What the system did during a run.
- **Memory DNA**: A reusable lesson with evidence and boundaries.
- **Skill**: A tested procedure the system may invoke.
- **Capability**: Something the system has demonstrated it can do.
- **Verse**: An alternative approach or execution branch.
- **Verification**: The checks used to judge the result.

Use the branded terms only when they add meaning. Prefer “alternative approach” before “Verse” and “source record” before “provenance” in introductory copy.

## Interface Copy

Preferred headings:

- “Start a task.”
- “See what the agent did.”
- “Check the result.”
- “Review reusable experience.”
- “Compare with the baseline.”

Preferred actions:

- “Start run”
- “Review plan”
- “Allow once”
- “Deny action”
- “Run checks”
- “View source trace”
- “Keep task-local”
- “Approve memory”
- “Test skill”
- “Compare results”

## Honest Status Labels

Use: `Draft`, `Running`, `Blocked`, `Needs review`, `Verified`, `Failed`, `Deprecated`, and `Rolled back`.

Do not use `Learned`, `Trusted`, `Safe`, or `Solved` without a defined evidence threshold and visible supporting result.
