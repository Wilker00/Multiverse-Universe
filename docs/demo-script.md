# Three-Minute Demo Script

## 0:00–0:30 — Problem

Show the task composer. Explain that coding agents often produce plausible changes without preserving the exact repository, permissions, checks, model route, or evidence needed to trust and reuse the result.

## 0:30–1:05 — Inspect and approve

Enter a public repository URL and full commit SHA. Run inspection. Show the detected stack, exact install and check commands, runner image, no-network runtime policy, and plan digest. Accept the immutable plan.

## 1:05–1:50 — Execute

Start the task. Show the OpenShell boundary, Nemotron tier, tool timeline, check result, and patch. State that Nebius Token Factory supplies inference and the provider credential never enters the sandbox.

## 1:50–2:25 — Evidence and memory

Open the manifest, trace, checks, and diff summary. Explain that a public repository receives `checks_passed`, not `verified`. Show a reviewed memory candidate and the manual promotion boundary.

## 2:25–2:55 — Controlled comparison

Run or show a paired no-memory versus reviewed-memory evaluation under the same commit, plan, budget, routing, adapter, and sandbox policy. Point out that composite fallback runs are excluded from claims.

## 2:55–3:00 — Close

“Multiverse makes agent work inspectable, reproducible, and selectively reusable.”
