# Multiverse identity

Multiverse is a calm agent execution and learning workspace. The name on every page is Multiverse, set in the header as the lowercase word multiverse. Do not name a page Runo. External products may inform density or interaction quality, but they never determine the final arrangement or shape language.

Before writing public product copy, read `docs/product/PRD.md`. Describe Multiverse as a persistent agent execution and verified-memory product, not a generic creative workspace, content studio, or multi-agent spectacle. Keep the local fixture harness, real product, and future vision explicitly separate.

The header wordmark is live IBM Plex Sans text, not an image and not the mascot. Weight 700, ink, tight tracking. The mascot stays out of the header.

## Signature system

- Use a twin-oval signal before section eyebrows, media metadata, and mascot prompt labels. Build it with decorative CSS pseudo-elements so it never enters the accessible name.
- Media frames use `24px 24px 10px 24px`; the smaller bottom-right corner is the consistent media cut.
- Large hero media uses `30px 30px 12px 30px`.
- Media-card actions are 38px rounded squares with an 11px to 12px radius, not floating circles.
- Approved mascots sit on `--ink` stages. Their oval eyes and flat light body remain the primary character signature.

## Control geometry

- Primary and secondary text actions use `--radius-control: 14px`.
- Header and menu text controls use the same 14px radius.
- Keep icon-only controls circular for recognition and compact targeting.
- Keep pills only for mode switches, statuses, guide roles, and metadata that behaves like a chip.
- Do not add decorative notches, gradients, or pill shapes merely because a reference product uses them.

## Copy voice

- Use short verbs that describe the next real action: Run, Review, Verify, Compare, Approve, Reject, and Retry.
- Prefer task, run, trace, check, evidence, memory, skill, alternative, and next action. Introduce branded or technical terms only when they make the decision clearer.
- Use familiar words and one main idea per sentence. Define necessary technical language instead of assuming specialist knowledge.
- Keep guidance calm and direct. Do not use random encouragement, gamified streaks, or repeated prompts after a press.

## External reference boundary

- ElevenLabs may inform compactness and response speed only.
- OpenAI may inform editorial restraint only.
- Anthropic may inform the idea of a calm character guide only.
- Never reproduce another product’s combined card geometry, spacing, button silhouette, labels, or animation sequence.
